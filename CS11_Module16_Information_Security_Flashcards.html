AnalyzeTask A: What Went Wrong at the Dental Office?

Case: A small dental office in Lodi was hit by ransomware. Read the timeline, then explain which failures allowed the attack to succeed. Connect each failure to one of the four pillars of Internet security or to data backup, and identify which single change would have done the most to reduce the damage.
  1. The office computers hadn't installed Windows updates in eight months; the "remind me later" button was clicked every time.
  2. The free antivirus trial on the front-desk PC expired last spring and was never renewed.
  3. The receptionist opened an email attachment called Patient_Referral.docm from an unknown sender.
  4. The ransomware encrypted every file on the shared office drive and demanded payment.
  5. The only backup was an external drive that stayed plugged into the same computer. It was encrypted too.
0 words (aim for 60+)
Expert analysis:
  • Event 1, Pillar 2 (software updates): eight months of missed patches left known security holes open. Hackers can exploit a newly announced flaw in under 24 hours.
  • Event 2, Pillar 3 (security software): antivirus works only if it's running and updated. An expired trial gives no protection.
  • Event 3, Pillar 4 (safe, cautious behavior): never open attachments unless they're expected and scanned. This was the moment of infection, and it's also an interior threat caused by an uninformed user.
  • Event 5, data backup: the backup stayed connected on-site, so the ransomware reached it too. The reading warns that on-site backups are exposed to the same destructive forces as the originals.
  • Most important single change: an off-site (cloud) or disconnected backup on an automatic schedule. Prevention can fail, but a separate backup turns a disaster into an inconvenience: wipe the drives and restore. (Pillar 1, a firewall, wouldn't have stopped an attachment the user opened herself.)

EvaluateTask B: Choose the Best Backup Plan

Scenario: Daniela is a Delta photography student who freelances shooting quinceañeras and weddings. Her laptop holds 2 TB of client photos that can never be reshot. Which backup plan is best? Choose one and defend it against the other two, using ideas from the reading: off-site storage, full and incremental backups, scheduling, encryption, and provider disclaimers.
0 words (aim for 50+)
Expert evaluation: Plan 3 is clearly best.
  • Plan 1: backups made "when she remembers" are often weeks old, so new client shoots are unprotected. A drive kept on the same desk can be lost in the same fire, flood, theft, or power surge as the laptop.
  • Plan 2: the reading warns that cloud providers "do not typically ensure against data loss" and that users should keep their own copies for 100 percent assurance. With only one copy, an account lockout or provider error could wipe out everything.
  • Plan 3 gives her two independent copies: a fast local restore, plus an off-site copy that survives a local disaster. Scheduled incremental backups capture each day's new photos without recopying 2 TB, and encryption protects clients' private photos if the drive is stolen.
  • Trade-off: Plan 3 costs more (a drive plus a monthly fee), but for irreplaceable client work that she's paid for, the cost is easily justified.

CreateTask C: Write a Security Plan for a Small Business

Scenario: Valley Tax Help is a family-run tax-preparation office in Stockton with four employees, five Windows PCs, a Wi-Fi router, and a printer. They store clients' Social Security numbers and bank information. The owner asks you to write a one-page information security plan covering the machine, network, and Internet levels.

Self-assess your plan against this checklist:

0 of 7 criteria met
Model plan (one strong possibility):
  • Machine level: each employee gets a unique login with a strong password stored in a password manager. Turn on 2-step verification for email and tax software. Encrypt every PC's drive with BitLocker so a stolen laptop exposes nothing. Lock screens automatically after 5 minutes.
  • Backup: nightly automatic incremental backups to an encrypted cloud service (off-site), with a weekly full backup to an external drive kept in a locked cabinet and disconnected between backups so ransomware can't reach it.
  • Network level: employees use Standard accounts, and only the owner has Administrator rights, so malware can't easily install itself. The client-files folder gives read and write access only to preparers. Change the router's default password, use WPA2 or newer encryption, and put clients in the waiting room on a separate guest network.
  • Internet level: enable the Windows firewall and the router's firewall, set Windows and browsers to update automatically, and run a security suite that updates itself. Train staff twice a year on phishing: never click email links, type addresses directly, and don't open unexpected attachments.
  • Policy and law: every employee signs a network usage policy (no personal software, no USB drives, shred printed SSNs). Keep a written plan to notify clients if their data is ever stolen, as identity-theft and breach-notification laws require.
